# Subida a GitHub Pages

1. Descomprime `NEXUS_Global_Alpha_v1.2_GitHub.zip`.
2. Entra en la carpeta descomprimida.
3. Selecciona todos los archivos y carpetas, incluido `.nojekyll`.
4. Súbelos a la raíz del repositorio.
5. Verifica que la ruta sea `tu-repositorio/index.html`, no `tu-repositorio/NEXUS_Global_Alpha_v1.2/index.html`.
6. Abre `Settings → Pages → Deploy from a branch`.
7. Selecciona `main` y `/ (root)`.

GitHub no descomprime automáticamente un ZIP subido como archivo.

La base vectorial funciona sin servicios externos. Los mosaicos de detalle OpenStreetMap requieren conexión a Internet desde el navegador del jugador.
